# 📘 Computational Thinking & Literacy (Handout Summary)

## 1. Introduction: Rethinking Computational Thinking
- **Status**: Computing shapes modern society, requiring new ways of thinking and problem-solving.
- **Problem**: Education separates computer science from literacy, treating coding as a technical skill.
- **Central Argument**: Computational Thinking (CT) should be understood as a form of literacy.
- **Framework**:
  1. CT as literacy  
  2. CT through literacy  
  3. Literacy through CT  

## 2. What is Computational Thinking? 🤖
- **Definition**: A general problem-solving approach applicable across disciplines.
- **Key Skills**
  1. Navigating multiple levels of abstraction  
  2. Decomposing problems into manageable pieces  
  3. Algorithmic thinking  
  4. Representing data through models  
- **Core Insight**: CT focuses on how to think, not just how to code 💡  

## 3. Literacy: A Sociocultural Perspective 📖
- **Traditional View**: Literacy = reading and writing  
- **Expanded View**: Literacy = socially situated practices using tools and technologies  
- **Key Insight**: Literacy evolves with technology → CT becomes part of literacy  

## 4. Computational Thinking as Literacy 🧠
- **Core Idea**: CT is a new literacy embedded in modern sociotechnical practices  

### Material Dimension
- Computers act as a meta-medium  
- Technology reshapes communication  

### Cognitive Dimension
- **Abstraction**: focusing on essentials  
- **Automation**: rule-based procedures  
- **Analysis**: evaluating patterns  

### Social Dimension
- CT is shaped by context  

- **Key Insight**: CT transforms thinking and communication  

## 5. Computational Thinking through Literacy 🔄
- **Core Idea**: Literacy supports CT development  

### Mechanisms
1. **Pseudocode**: bridge between language and code  
2. **Narratives**: similar to algorithmic sequences  
3. **Writing ↔ Coding** (drafting ↔ debugging)  

- **Tools**: Scratch, Alice  
- **Key Insight**: Language helps understand computation  

## 6. Literacy through Computational Thinking ✍️
- **Core Idea**: CT enhances literacy  

### Applications
1. Form–Meaning–Use parallel  
2. Sequencing → better writing  
3. Debugging → reflection  

- **Key Insight**: Programming strengthens language learning  

## 7. New Media and Production 🚀
- Shift: consumption → production  
- Problem: passive use  
- Solution: CT enables creation  

## 8. Identity, Motivation, and Equity 🌍
- Motivation: creativity  
- Identity: active creator  
- Equity Issue: unequal access  
- Implication: broader participation  

## 9. Educational Implications 🎓
- **Integration**: Embed CT into literacy instruction  
- **Benefits**
  1. Better computational skills  
  2. Better language skills  
  3. Real-world relevance  

## 10. Conclusion 🧩
- **Main Claim**: CT is a fundamental 21st-century literacy  
- **Contribution**: integrates CS + literacy + media  
- **Future Direction**: interdisciplinary curriculum  

---

## 🔥 Overall Summary
- Computational thinking works in three ways:
  1. **as literacy**  
  2. **through literacy**  
  3. **for literacy**  

👉 CT = a new paradigm for thinking and expression in the digital age
